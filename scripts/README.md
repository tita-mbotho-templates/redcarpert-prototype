Run `npm ci` with Node 24. `npm run dev` generates the approved HTML pages and starts Vite; open http://localhost:5173/redcarpert-prototype/. After changing document data or adapters, restart development to regenerate HTML. Client scripts support Vite hot updates.

`npm run build` writes the static deployment to dist. `npm run preview` serves that build at http://localhost:4173/redcarpert-prototype/. No Node server or API is needed in production. Every approved URL has its own index.html; retired captures are source material only. The lookbook PDF is generated during build from the two local gallery photographs.

Pushes to main build and validate only. Deployment requires a manual workflow dispatch on main with the approval checkbox explicitly selected. A repository administrator should also configure the github-pages environment with required reviewers and main-only deployment rules. GitHub does not allow workflow YAML to create that environment policy. No deployment runs from this implementation branch.

Validation: `npm test`, `npm run lint`, `npm run typecheck`, `npm run build`, then `npm run test:dist`. With preview running on port 4173, `npm run test:browser` checks all approved routes at 1440/768/390px, refresh, local resources, enquiry dialog, reader controls, native menus, category/sample navigation, image enlargement, scroll controls and PDF download. An additional iPhone-UA/touch case checks native swipe, Home reset, enquiry and mobile menu behavior. Chromium must be installed (`npm run setup`). Browser measurements/screenshots are written to /tmp, outside the deployment.
